Ticket Boleto

Personal Project Oct 2024 – Feb 2025

A real-time ticket booking website for concerts, sports events, and movies, built with concurrency handling to prevent overbooking and a secure end-to-end checkout flow.

Highlights

  • Created a ticket booking website for concerts, sports events, and movies with concurrency handling to prevent overbooking.
  • Implemented JWT authentication and Google OAuth, reducing login time by 30% and improving session security, resulting in zero unauthorized access incidents during testing.
  • Integrated a secure payment gateway, extensively tested to reduce transaction failures by 15%, ensuring smoother and more reliable payments in a live environment.

Tech Stack

React.js Node.js Express MongoDB JWT Google OAuth
