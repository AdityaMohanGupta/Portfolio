KAI — LLM Agent & MCP Server Framework

Consat Orahi Nov 2025 – Present Associate Software Engineer

An AI platform (internal name DDA, shipped externally as kAI) that lets non-technical employees ask plain-English questions about company data and get instant answers and charts, build no-code automation workflows, and query uploaded documents — with every customer's data kept strictly isolated. My work centered on the identity & permissions layer and the framework that lets AI agents safely call real external tools.

What I Built

  • Built the identity and permissions system — tenant/subtenant hierarchy, roles, and a full audit trail of every user and team change — the single largest area of my contribution to the service.
  • Built the majority of the MCP tool-calling bridge that lets AI agents securely call real external systems — Jira, a graph database, direct SQL — with the right user's credentials, plus specific tools like SQL execution and S3 file reading.
  • Built an end-to-end AI regression-testing system (backend, orchestration, and the admin UI) that automatically replays a bank of real questions against the live pipeline to catch quality drift before a customer notices.
  • Built part of the connectors screen where admins link external tools like Jira and Outlook via OAuth2, and fixed a production bug where a broken message on the internal message bus would retry forever instead of being discarded.

Tech Stack

Python FastAPI FastMCP AutoGen Java Spring Boot React.js Keycloak OAuth2 PostgreSQL NATS Docker Kubernetes
KAI is built as a team of specialized AI agents (understand the question, write the query, draw the chart, verify the answer) rather than one model doing everything — each step is simpler to get right, test, and fix in isolation. This is a proprietary enterprise system built at Consat Orahi — source code and live demo are confidential and not publicly available.
