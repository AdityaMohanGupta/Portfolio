Airlinq eSIM Fleet Orchestrator

Consat Orahi Nov 2025 – Present Associate Software Engineer

A cloud-native platform that lets a company remotely manage, connect, and monitor a fleet of thousands of eSIM-powered IoT devices — activating them, switching carriers, or shutting them off instantly instead of sending a technician to each one. My work centered on the identity & permissions layer, audit logging, and bulk device onboarding that keep the platform secure and usable at enterprise scale.

What I Built

  • Built the multi-tenant identity and permissions system — sign-up invitations, roles, and org-level access control that keeps one company's devices completely invisible to another company sharing the platform.
  • Built a full audit trail across two core services, capturing the before-and-after value of every change to users, organizations, devices, and rules — so "who changed this and when" is a single lookup, not a log hunt.
  • Built the bulk-upload feature for devices and connectivity profiles, letting an admin import thousands of records from a spreadsheet in one go, with validation that catches duplicate or malformed rows.
  • Built part of the device-management dashboard (data-usage display, dropdown cleanup) and wrote the auto-generated Swagger/OpenAPI docs other teams integrate against.
  • Fixed a set of multi-tenant correctness bugs — admins unable to see org-wide "everyone" records, duplicate company names being allowed, and incorrect KPI dashboard counts.

Tech Stack

Java 21 Spring Boot (WebFlux) gRPC Kafka Redis PostgreSQL Keycloak OAuth2 Swagger/OpenAPI Docker Kubernetes
Airlinq is built as seven independent backend services (rule engine, order orchestrator, retry scheduler, Thales device adapter, and more) — my work concentrated in the identity/permissions and audit-log services above. This is a proprietary enterprise system built at Consat Orahi — source code and live demo are confidential and not publicly available.
